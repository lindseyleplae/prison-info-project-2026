## Descripción general

Prison Visitor Guide está diseñado para respetar la privacidad de los usuarios. Este sitio recopila información mínima y no rastrea, perfila ni monetiza a sus usuarios de ninguna manera.

## Qué no recopila este sitio

Este sitio no usa cookies, píxeles de rastreo, redes publicitarias ni ningún mecanismo para identificar o perfilar a usuarios individuales. En concreto:

-   Este sitio no establece ni lee cookies
-   No se recopila información personal al navegar por este sitio
-   No existen cuentas de usuario y no se requiere registro
-   No se muestra publicidad
-   No se venden ni se comparten datos con terceros
-   No hay rastreo entre sitios de ningún tipo (ni Google Analytics, ni Facebook Pixel, etc.)

## Conteo anónimo de visitas

Para saber si el sitio está llegando a las personas, se cuentan las visitas a las páginas usando GoatCounter, un servicio de código abierto diseñado para la privacidad. Este conteo registra la página visitada, el sitio de referencia, el tipo de navegador y el país — y nada que identifique a una persona: sin cookies, sin huella digital, sin identificadores personales y sin uso publicitario. Las propias prácticas de privacidad de GoatCounter se describen en la [política de privacidad de GoatCounter](https://www.goatcounter.com/help/privacy). El conteo de visitas no puede revelar quién visitó — solo que una página fue visitada.

## Alojamiento

Este sitio está alojado en GitHub Pages. GitHub puede recopilar registros básicos del servidor (como direcciones IP y solicitudes de páginas) como parte de su infraestructura de alojamiento estándar. Estos datos están controlados por GitHub, no por Prison Visitor Guide. Las prácticas de privacidad de GitHub se describen en la [Declaración de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Envíos de contacto y comentarios

Cuando los usuarios envían correcciones, sugerencias o preguntas a [prisonvisitorguide@gmail.com](mailto:prisonvisitorguide@gmail.com), la dirección de correo electrónico y cualquier información incluida en el mensaje son recibidas por Prison Visitor Guide. Esta información:

-   Se usa únicamente para responder al mensaje y mejorar el contenido del sitio
-   No se comparte con ningún tercero
-   No se agrega a ninguna lista de correo ni base de datos
-   No se usa para marketing ni solicitudes

## Enlaces externos

Este sitio contiene enlaces a sitios web externos, incluyendo agencias gubernamentales, organizaciones de defensa y otros recursos. Al hacer clic en estos enlaces, los usuarios acceden a sitios con sus propias prácticas de privacidad, que no están controladas por Prison Visitor Guide. Se recomienda revisar de forma independiente las políticas de privacidad de los sitios externos.

## Privacidad de los menores

Este sitio no recopila conscientemente información de menores de 13 años. No se recopila información personal de ningún usuario, sin importar su edad, según se describe arriba.

## Cambios a esta política

Esta política de privacidad puede actualizarse si cambian las prácticas de datos del sitio. Cualquier cambio importante se indicará en esta página con la fecha de la revisión más reciente.
